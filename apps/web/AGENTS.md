# Agent instructions

This app is part of the Vinca repository. Before doing any work, read the
repository-level documents, in this order:

1. `../implementation docs/projectcontext.md` (current state, freeze exceptions)
2. `../implementation docs/prd.md` (authoritative requirements)
3. `../implementation docs/ui-handoff-checklist.md` (frontend completion & handoff gate)

Then follow the repository-wide rules in `../AGENTS.md`, including the
validation freeze: do not run tests, typecheck, builds, watchers or installs
unless the user explicitly authorises it.

Use the `@/` import alias for `src/`.
